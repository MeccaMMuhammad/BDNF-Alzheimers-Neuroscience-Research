## First decide whether your BDNF repository already exists

1. Visit the target repository link above.
2. **If it already exists:** do not create a duplicate. Open the repository → **Add file** → **Upload files**. Upload the contents of `01-UPLOAD-THIS-REPOSITORY` (not that containing folder), preserving `originals`, `polished`, and `research-update-2026` paths. GitHub should identify same-name files for replacement in the commit. If browser uploads are cumbersome, use GitHub Desktop to synchronize this entire folder with the existing repository.
3. **If it doesn't exist:** visit https://github.com/new, name the repository `BDNF-Alzheimers-Neuroscience-Research`, choose Public, and leave the automatic README checkbox off. Create it and use **uploading an existing file** to add the contents of `01-UPLOAD-THIS-REPOSITORY`.

**Important:** GitHub does not automatically extract ZIP contents. Extract the ZIP in Windows Explorer first. Drag the files and subfolders **inside** `01-UPLOAD-THIS-REPOSITORY` to the upload area. The root of your repository must contain `README.md`, `originals/`, `polished/`, and `research-update-2026/`.

## Upload steps (Windows browser)

1. Right-click the downloaded ZIP → **Extract All**.
2. Open `01-UPLOAD-THIS-REPOSITORY`.
3. In your GitHub repository click **Add file → Upload files** (on an empty repo, click **uploading an existing file**).
4. Drag **all the items inside** the extracted repository folder onto the GitHub upload page.
5. Confirm paths such as `research-update-2026/BDNF_Research_Update_2026.pdf`, `polished/BDNF_Research_Proposal_Polished_2026.pdf`, and `originals/2019_Original_Presentation.pdf` are shown.
6. Commit changes with message `Add 2026 literature update and refreshed neuroscience portfolio`. If GitHub asks to create a branch instead of direct commit, follow its prompt and merge the proposed changes.
7. Return to the repository main page. Verify its README displays the 2026 research update near the top and check the PDF links.
